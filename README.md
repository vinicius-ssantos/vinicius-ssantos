## About me

I'm a Backend Software Engineer from São Paulo, Brazil, focused on Java, Spring and services where security, consistency and production stability matter.

I started my career in QA and API automation before moving into backend development. That path still shapes how I engineer systems: I think about failure modes, concurrency, recovery and observability before treating the happy path as complete.

At UOL, I work with authentication and account-protection services, API integrations, contract standardization, automated delivery and production support. Outside work, I build public portfolio systems that make architectural decisions and trade-offs inspectable through code, tests, ADRs and runbooks.

## What I build

- Reliable REST APIs and backend services with Java and Spring
- Security-sensitive authentication, authorization and account-protection flows
- Persistent idempotency, state machines, audit trails and failure recovery
- Integration and architecture tests with JUnit, Testcontainers, WireMock and ArchUnit
- Observable services with structured logs, metrics, traces, dashboards and alerts
- Reproducible delivery with Docker, Kubernetes and CI/CD pipelines
